# 牛牛核心 `pb_core`

查看进程状态、控制台入口、插件列表，以及更新检查与重启等管理命令。`#pallas` 可供号主在群内排查；其余管理命令默认面向超管。

**类型**：本体 core（默认加载）

## 安装

默认加载，无需单独安装。

## 用法

| 命令 / 触发 | 场景 | 说明 |
| --- | --- | --- |
| `运行状态`（发 `#pallas`） | 群内 / 私聊 | 当前运行状态 |
| `牛牛控制台` | 群内 / 私聊 | 网页入口 |
| `牛牛插件` | 群内 / 私聊 | 当前插件列表 |
| `牛牛更新` | 私聊 | 检查 Bot / WebUI / 插件与自动更新；可应用 |
| `牛牛更新 应用` / `全部` | 私聊 | 按 WebUI→插件→Bot 顺序应用 |
| `牛牛更新 bot` / `webui` / `插件` | 私聊 | 只应用单项 |
| `牛牛更新 自动 bot\|webui\|插件 开\|关` | 私聊 | 开关对应自动更新 |
| `牛牛更新 汇报 开\|关` | 私聊 | 自动更新成功后是否私聊超管 |
| `牛牛更新 汇报号 <QQ>\|0\|自动` | 私聊 | 指定发送汇报的牛（0=任选在线） |
| `牛牛重启` | 群内 / 私聊 | 重新启动 |
| `牛牛添加号主 号主QQ… [牛 目标牛QQ]` | 私聊 | 默认为当前私聊牛添加号主；带 `牛 目标牛QQ` 时为指定牛初始化并添加 |

精确说明以 **牛牛帮助** 为准。`#pallas` / `牛牛插件` 看当前进程视角。`牛牛更新` 仅超管私聊；应用更新复用 WebUI / 自动更新同一套 apply 路径。自动更新与汇报开关也可在 WebUI「更新」页配置（含汇报用牛 QQ）。通过命令触发重启时，接收命令的牛重新连上后会私聊通知触发者（临时文件 `data/pb_core/restart_notify_pending.json`，约 10 分钟内有效）。

## 命令权限（代码默认）

| 命令 ID | 默认等级 |
| --- | --- |
| `pb_core.status` | 号主 |
| `pb_core.console` | 仅超管 |
| `pb_core.plugins` | 仅超管 |
| `pb_core.update_check` | 仅超管 |
| `pb_core.restart` | 仅超管 |
| `pb_core.add_bot_admin` | 仅超管 |

实际生效等级以控制台「命令权限」为准。面向用户的 usage 不要写死角色名。

## 配置

无独立用户配置页；行为由核心运行时与控制台控制。

## 排障

| 现象 | 处理 |
| --- | --- |
| 状态信息不全 | 检查进程角色、Git 环境与运行脚本是否可探测 |
| 重启无效 | 确认部署环境支持调度重启脚本 |
