# 牛牛喝酒 `drink`

让牛牛喝酒、醒酒，并影响后续表现（聊天、做梦、轮盘、夺舍等）。需要切换醉酒状态时用本插件。

**类型**：本体 core（默认加载）

## 安装

默认加载，无需单独安装。

## 用法

| 命令 / 触发 | 场景 | 说明 |
| --- | --- | --- |
| `牛牛喝酒` / `牛牛干杯` / `牛牛继续喝` | 群内 | 增加醉酒度，可能睡着 |
| `牛牛醒一醒` / `牛牛别喝了` | 群内 | 立即醒酒；做梦时也会一并醒梦 |

精确命令与「何人可用」以群内 **牛牛帮助** 为准。酒后搭话由 [llm_chat](../llm_chat/README.md) 处理。

## 醉酒度怎么变

按 **「处理消息的那只牛 × 当前群」** 独立计数（多牛同群互不影响）。

| 动作 | 变化 |
| --- | --- |
| 成功触发喝酒命令一次 | **+1**（有命令冷却，冷却内再发通常静默） |
| 每次喝酒后随机 **60～600 秒** 的定时醒酒 | **-1**（多喝会叠多个定时器） |
| `牛牛醒一醒` / `牛牛别喝了` | 直接 **清零** |
| 进程启动 | 全量清零 |

酒后对话（`@牛牛` / `牛牛 + 文本`）要求该牛在本群 `drunkenness > 0`。  
若开启「酒后对话附带语音」，还会用醉酒度做阈值（默认 ≥1 才可能文+音），见 [llm_chat](../llm_chat/README.md) / [tts](../tts/README.md)。

## 命令权限（代码默认）

| 命令 ID | 默认等级 |
| --- | --- |
| `drink.drink` | 所有人 |
| `drink.sober_up` | 所有人 |

可在控制台插件页或「命令权限」覆盖。面向用户的 usage 不要写死角色名。

## 配置

无独立 `config.py`；醉酒状态与相关冷却走运行时状态。本群开关见帮助图 / 控制台插件管理。

酒后是否自动念回文，不在本插件配置，而在控制台 **智能对话** 段：

| 配置项 | 环境变量 | 含义 |
| --- | --- | --- |
| 酒后对话附带语音 | `CHAT_TTS_ENABLE` | 总开关 |
| 最低醉酒度 | `DRUNK_TTS_MIN_DRUNKENNESS` | 默认 `1`（见上表醉酒度规则） |
| 回文最短字数 | `DRUNK_TTS_MIN_CHARS` | 默认 `6` |

## 排障

| 现象 | 处理 |
| --- | --- |
| 喝酒无反应 | 群冷却内可能静默；查日志与发送是否成功 |
| 多牛只有一只反应 | 检查多牛部署与消息路由；各牛醉酒度独立 |
| 一直不醒 | 发 `牛牛醒一醒`，或等待自动清醒 |
| 酒后不念语音 | 确认已喝酒（醉酒度达标）、回文够长，且 `CHAT_TTS_ENABLE` 与 TTS 已开 |

## 源码

[`packages/drink/`](../../../packages/drink/)

- `__init__.py`：喝酒 / 醒酒元数据
- `handlers.py`：醉酒度变化
- `startup.py`：运行时联动

多牛同群时各牛醉酒状态独立。醒酒可能顺带结束做梦等联动状态。
