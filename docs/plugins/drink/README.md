# 牛牛喝酒 `drink`

让牛牛喝酒、醒酒，并影响后续表现（聊天、做梦、轮盘、夺舍等）。需要切换醉酒状态时用本插件。

**类型**：本体 core（默认加载）

## 安装

默认加载，无需单独安装。

## 用法

| 口令 / 触发 | 场景 | 说明 |
| --- | --- | --- |
| `牛牛喝酒` / `牛牛干杯` / `牛牛继续喝` | 群内 | 增加醉酒度，可能睡着 |
| `牛牛醒一醒` / `牛牛别喝了` | 群内 | 立即醒酒；做梦时也会一并醒梦 |

精确口令与「何人可用」以群内 **牛牛帮助** 为准。酒后搭话由 [llm_chat](../llm_chat/README.md) 处理。

## 命令权限（代码默认）

| 命令 ID | 默认等级 |
| --- | --- |
| `drink.drink` | 所有人 |
| `drink.sober_up` | 所有人 |

可在控制台插件页或「命令权限」覆盖。面向用户的 usage 不要写死角色名。

## 配置

无独立 `config.py`；醉酒状态与相关冷却走运行时状态。本群开关见帮助图 / 控制台插件管理。

## 排障

| 现象 | 处理 |
| --- | --- |
| 喝酒无反应 | 群冷却内可能静默；查日志与发送是否成功 |
| 多牛只有一只反应 | 检查多牛部署与消息路由 |
| 一直不醒 | 发 `牛牛醒一醒`，或等待自动清醒 |

## 源码

[`packages/drink/`](../../../packages/drink/)

- `__init__.py`：喝酒 / 醒酒元数据
- `handlers.py`：醉酒度变化
- `startup.py`：运行时联动

多牛同群时各牛醉酒状态独立。醒酒可能顺带结束做梦等联动状态。
