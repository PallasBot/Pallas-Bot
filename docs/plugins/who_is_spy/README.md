# 牛牛卧底 `who_is_spy`

群内谁是卧底：讨论、匿名投票与复盘。需要派对游戏时安装本官方插件。

**类型**：官方插件（需安装）

## 安装

控制台插件商店，或：

```bash
uv run pallas ext install pallas-plugin-who-is-spy
```

## 用法

| 命令 / 触发 | 场景 | 说明 |
| --- | --- | --- |
| `牛牛卧底` | 群内 | 创建房间 |
| `牛牛加入` / `牛牛退出` | 群内 | 筹备阶段加入或退出 |
| `牛牛发身份 [潜藏人数] [白板] [暗牌\|明牌]` | 群内 | 房主开局并下发词语 |
| `@牛牛 + 描述` | 群内 | 讨论阶段记为述词 |
| `牛牛投票` | 群内 | 房主提前开始投票 |
| 私聊回复数字序号或 `0` | 私聊 | 匿名投票；`0` 弃权 |
| `牛牛局势` / `牛牛结束` | 群内 | 查看局势或结束房间 |

精确命令与「何人可用」以群内 **牛牛帮助** 为准。同群同时仅一局。发词与投票说明优先私聊；需先加牛牛好友。

## 命令权限（代码默认）

| 命令 ID | 默认等级 |
| --- | --- |
| `who_is_spy.open` | 所有人 |
| `who_is_spy.join` | 所有人 |
| `who_is_spy.start` | 所有人 |
| `who_is_spy.status` | 所有人 |
| `who_is_spy.end` | 所有人 |

实际生效等级以控制台「命令权限」为准。

## 配置

控制台对应插件页。常用项含最少 / 最多人数、默认卧底与白板数量、是否暗牌、述词字数上限等。

词库默认：`data/who_is_spy/undercover_words.json`（首次从内置资源复制，可自行增补）。

## 排障

| 现象 | 处理 |
| --- | --- |
| 收不到词语或投票私聊 | 先加牛牛好友；若开启邮箱兜底，检查 QQ 邮箱 |
| 本群已有房间 | 发 `牛牛结束` 或等待自动清理 |
| 述词无回复 | 多牛同群时须 `@` 本局主持牛 |
| 词库为空 | 检查上述 json 或内置 `resource/who_is_spy/` |
