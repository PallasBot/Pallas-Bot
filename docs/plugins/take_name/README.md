# 自动夺舍 `take_name`

定时随机模仿群友名片；醉酒时可能更频繁。需要「自动改名片」氛围玩法时保留本插件；不需要可在本群帮助里关掉。

**类型**：本体 core（默认加载）

## 安装

默认加载，无需单独安装。

## 用法

无用户主动命令。定时任务会随机改牛牛名片；醉酒时可能更活跃。精确说明以群内 **牛牛帮助** 为准。

## 命令权限（代码默认）

无用户命令。

## 配置

无独立 `config.py`；通常通过本群插件开关控制。相关行为受 [喝酒](../drink/README.md) 状态影响。

## 排障

| 现象 | 处理 |
| --- | --- |
| 从不改名 | 概率不高；确认插件未关闭 |
| 改名失败 | 确认牛牛有修改群名片权限 |

[`packages/take_name/`](../../../packages/take_name/)

- `startup.py`：定时任务与联动
