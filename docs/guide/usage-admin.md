# 日常管理

> 目标：登录控制台管理 Bot，并在群内确认常用功能可用
> 准备：Bot 已启动且能打开 `/pallas/`；尚未连 QQ 见 [连接 QQ](/guide/connect-qq)
> 完成之后：能操作控制台，并在群里验收常用功能

## 1. 登录控制台：进入管理页面

1. 打开 `http://<主机>:8088/pallas/`（端口以 `pallas.toml` 的 `[bootstrap] port` 为准）
2. 输入启动日志中的控制台密码
3. 群里发 `牛牛帮助`，对照帮助图确认功能可用

能进入控制台并收到帮助图，说明控制台和群内功能均可使用。面板使用说明见 [网页控制台](/guide/web-console)。

## 2. 在控制台完成常用管理：保存配置

| 任务 | 操作 |
| --- | --- |
| 配置从哪改 | 见 [配置从哪改](config.md) |
| 配置号主 | **实例与连接** → 初始化 / 编辑 `admins`；详见 [号主](bot-owner.md) |
| 安装决斗、MAA 等 | **插件商店** → 安装 → 重启 Bot |
| 配 Provider、画画、唱歌等能力 | **AI 配置** |
| 改命令权限 | **命令权限** |
| 关闭某牛全部玩法 | **插件** → **全实例禁用** |
| 排查无响应 | **运行日志**、**日志报错** |
| 添加 NapCat 账号 | **协议端实例** 或 `/pallas/protocol` |
| 备份数据库 | **数据库** |

保存后写入 `data/pallas_config/webui.json`。这是控制台的保存结果，通常不要手动编辑；需要修改时回到 **AI 配置**、**通用配置** 或对应页面保存。

已接热重载的配置会在保存后由运行中的 Bot 重新读取，不用中断服务。端口、数据库、插件安装或卸载等变更需要重启 Bot；这是正常行为，详见 [网页控制台](/guide/web-console)。

## 3. 在群里确认功能：查看帮助图

完整列表以 **牛牛帮助** 为准。摘要见 [命令与功能](/guide/usage)。

| 命令 | 作用 |
| --- | --- |
| `牛牛帮助` | 功能总览 |
| `牛牛连通` | 测试外部服务（含 AI） |
| `牛牛喝酒` / `醒一醒` | 喝酒状态 |
| `牛牛轮盘` | 轮盘玩法 |

## 按使用场景排查

| 现象 | 排查 |
| --- | --- |
| 群里完全没反应 | 协议端是否在线；牛是否在群；[FAQ](/deploy/faq) |
| 某功能不可用 | 插件是否安装；帮助图里是否被关掉 |
| AI 不可用 | 控制台 AI 地址；发 `牛牛连通` 测试 |
| 忘记控制台密码 | [FAQ](/deploy/faq) |
