# 网页控制台

> **目标**：登录网页控制台，并按首次使用顺序完成基本设置  
> **准备**：Bot 已启动，浏览器能打开 `http://<主机>:8088/pallas/` 与启动日志中的密钥  
> **完成之后**：能管理协议端、实例、插件与配置，查看运行日志

网页控制台随 Bot 一起启动，登录后即可管理协议端、实例、插件与配置。配置存放位置见 [配置从哪改](config.md)。

::: tip
手机或窄窗口也能用。侧栏可收起；表格类页面可横向滑动。
:::

## 第 1 步：打开并登录

| 项 | 值 |
| --- | --- |
| 地址 | `http://<主机>:8088/pallas/` |
| 端口 | `pallas.toml` → `[bootstrap] port`，默认 **8088** |
| 首次密码 | 启动日志打印；密钥文件在 `data/pallas_console/` |

1. 在浏览器打开上表地址。本机使用 `127.0.0.1`，服务器使用 IP 或域名。
2. 输入启动日志中的控制台初始密码。
3. 看到首页运行概览和侧栏后，说明登录成功。

::: warning 注意：生产安全
不要长期开开发模式（会跳过登录）。公网务必 HTTPS + 强密码，不要把控制台裸暴露到公网。
:::

::: details 排障：密码遗忘与重置
- 忘了：见 [FAQ · 控制台密码](/deploy/faq)（按页内说明重置）
- 换密码：登录后在控制台账号 / 安全相关入口修改（以当前版本界面为准）
:::

## 第 2 步：完成首次设置

控制台能打开只表示 Bot 本体已启动。按下面顺序完成账号和功能设置：

1. **连接 QQ 账号**：进入 **协议端实例**，按 [连接 QQ](connect-qq.md) 新建或接入账号。完成后，在群里发送 **牛牛帮助**；能收到帮助图，说明账号和消息链路已经正常。
2. **配置该账号的号主**：进入 **实例与连接**，按 [号主](bot-owner.md) 设置 `admins`。
3. **安装需要的玩法扩展**：进入 **插件商店**，按 [安装插件](install-plugins.md) 安装并重启 Bot。
4. **配置日常能力**：在 **AI 配置**、**通用配置** 和 **命令权限** 中设置聊天、媒体、语料与权限。

## 需要改东西时去哪里

### 账号与连接

- **仪表盘**：查看在线状态和消息量。
- **实例与连接**：配置号主，查看框架已接入的账号。
- **协议端实例**：管理 NapCat 或其他协议端。

### 插件与权限

- **插件**：打开单个插件页修改配置，或使用 **全实例禁用** 关闭插件。
- **插件商店**：安装、卸载或更新决斗、MAA 等官方扩展。
- **命令权限**：调整命令的可用范围。

### AI 与通用配置

- **AI 配置**：配置 Provider、聊天、媒体能力，以及接话工具与联网搜索策略。AI 相关说明见 [AI 扩展](ai.md)。
- **AI 观测**：查看会话、记忆、人物和任务；见 [观测与策略](ai.md#聊得起来之后ai-观测与对话策略)。
- **通用配置**：配置语料和外部服务地址。

### 数据与日志

- **运行日志** 与 **日志报错**：查看运行状态和异常。
- **数据库**：备份或清理数据库。

不确定某个功能属于插件、AI 还是通用设置时，先看 [配置从哪改](config.md)。日常操作清单见 [日常管理](usage-admin.md)。

## 保存后会发生什么

保存配置会写入 `data/pallas_config/webui.json`。这是控制台的保存结果，通常不需要手动编辑。

- **保存插件页、AI 配置、通用配置或命令权限**：多数会热重载，不中断服务。
- **安装、卸载或升级官方插件**：重启 Bot 后加载新版本。
- **修改 `pallas.toml` 的端口、数据库或超管**：重启 Bot 后读取新设置。

热重载是让正在运行的 Bot 重新读取配置。控制台显示“需重启”时，再停止并重新启动 Bot。

同名项由 `webui.json` 覆盖 `pallas.toml`。保存后仍未生效时，先检查控制台页面和运行日志。

::: details 开发：配置合并顺序
`pallas.toml` → `.env` → `webui.json`（后者优先）。合同见 [配置存储](/developer/architecture/config-storage)。
:::

## 日常验收与常见检查

### 群内验收

- 发送 `牛牛帮助`：确认帮助图与当前可用命令。
- 发送 `牛牛连通`：测试外部服务和 AI 连接。
- 使用 `牛牛喝酒` / `醒一醒`、`牛牛轮盘` 等基础命令：确认群内命令链路。

完整命令列表见 [命令与功能](usage.md)。

### 常见检查

- **群里完全没反应**：确认协议端在线、账号已在群，再看 [FAQ](/deploy/faq)。
- **某功能不可用**：确认插件已安装，且没有在帮助图或插件页被关闭。
- **AI 不可用**：在 **AI 配置** 检查 Provider，发送 `牛牛连通` 测试。
- **忘记控制台密码**：见 [FAQ](/deploy/faq)。
