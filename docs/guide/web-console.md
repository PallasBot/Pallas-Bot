# 网页控制台

网页控制台随 Bot 一起启动，不需要额外部署。它用于连接协议端、管理实例和插件、修改配置以及查看运行日志。

这页完成两件事：登录控制台，并按首次使用顺序完成基本设置。配置存放位置见 [配置从哪改](config.md)。

::: tip
手机或窄窗口也能用。侧栏可收起；表格类页面可横向滑动。
:::

## 第 1 步：打开并登录

| 项 | 值 |
| --- | --- |
| 地址 | `http://<主机>:8088/pallas/` |
| 端口 | `pallas.toml` → `[bootstrap] port`，默认 **8088** |
| 首次密码 | 启动日志打印；密钥文件在 `data/pallas_console/` |

1. 在浏览器打开上表地址。本机使用 `127.0.0.1`，服务器使用 IP 或域名。
2. 输入启动日志中的控制台初始密码。
3. 看到首页运行概览和侧栏后，说明登录成功。

::: warning
不要长期开开发模式（会跳过登录）。公网务必 HTTPS + 强密码，勿把控制台裸暴露到公网。
:::

::: details 忘了密码 / 换密码
- 忘了：见 [FAQ · 控制台密码](/deploy/faq)（按页内说明重置）
- 换密码：登录后在控制台账号 / 安全相关入口修改（以当前版本界面为准）
:::

## 第 2 步：完成首次设置

控制台能打开只表示 Bot 本体已启动。按下面顺序完成账号和功能设置：

| 顺序 | 去做 | 侧栏 / 文档 |
| --- | --- | --- |
| 1 | 连接 QQ 账号 | **协议端实例** · [连接 QQ](connect-qq.md) |
| 2 | 配置该账号的号主 | **实例与连接** · [号主](bot-owner.md) |
| 3 | 安装需要的玩法扩展 | **插件商店** · [安装插件](install-plugins.md) |
| 4 | 按需配置聊天、媒体、语料与权限 | **AI 配置** / **通用配置** / **命令权限** |

完成第 1 步后，在群里发送 **牛牛帮助**。能收到帮助图，说明账号和消息链路已经正常。

## 需要改东西时去哪里

| 任务 | 去哪 |
| --- | --- |
| 看是否在线、消息量 | **仪表盘** |
| 配号主、看框架里有哪些牛 | **实例与连接** |
| 管 NapCat / 协议端 | **协议端实例**（或协议端管理） |
| 改某个插件配置 | **插件** → 点插件名 |
| 全实例关掉某插件 | **插件** → **全实例禁用** |
| 装 / 卸决斗、MAA 等 | **插件商店** |
| 改命令谁能用 | **命令权限** |
| 配 Provider、聊天、媒体能力 | **AI 配置** · [AI 扩展](ai.md) |
| 看会话、记忆、人物、任务等 | **AI** → **AI 观测** · [观测与策略](ai.md#聊得起来之后ai-观测与对话策略) |
| 工具清单与覆盖 / 联网搜索 | **AI 配置 → 接话 → 工具 / 策略** |
| 配语料、外部服务 | **通用配置** |
| 看报错与运行日志 | **运行日志** / **日志报错** |
| 备份、清理库 | **数据库** |

不确定某个功能属于插件、AI 还是通用设置时，先看 [配置从哪改](config.md)。日常操作清单见 [日常管理](usage-admin.md)。

## 保存后会发生什么

保存配置会写入 `data/pallas_config/webui.json`。这是控制台的保存结果，通常不需要手动编辑。

| 操作 | 结果 |
| --- | --- |
| 保存插件页、AI 配置、通用配置或命令权限 | 多数会热重载，不中断服务 |
| 安装、卸载或升级官方扩展 | 重启 Bot 后加载新版本 |
| 修改 `pallas.toml` 的端口、数据库、超管 | 重启 Bot 后读取新设置 |

热重载是让正在运行的 Bot 重新读取配置。控制台显示“需重启”时，再停止并重新启动 Bot。

同名项由 `webui.json` 覆盖 `pallas.toml`。保存后仍未生效时，先检查控制台页面和运行日志。

::: details 开发向：合并顺序
`pallas.toml` → `.env` → `webui.json`（后者优先）。合同见 [配置存储](/developer/architecture/config-storage)。
:::
