# `@牛牛` 与复读

Pallas-Bot 的群聊回复分两条路径：

| 路径 | 触发条件 | 行为 |
| --- | --- | --- |
| **复读 / 接话** | 日常群聊自动 | 优先本机语料；少数「强场景」可让 AI 选句 / 轻润色 |
| **`@牛牛` 闲聊** | 明确 @ 牛 | 走 AI 闲聊（仍带牛格与群味） |

默认策略：**语料是嘴，AI 是教练**——不是把整群聊天交给通用大模型。

## 复读 / 接话

- 日常群聊自动触发，优先本机学到的语料
- 受牛格、群风格、单群表达参考影响
- **多数时候不走 AI**；只有机会合适时才会尝试

### 强场景与弱场景

系统会把接话机会分成两档（内部名 `scene_tier`）：

| 档位 | 大致何时出现 | AI 怎么参与 |
| --- | --- | --- |
| **强场景** | 有人 @、明显接话 cue 且有候选语料、或刚来回过几句且有语料池 | 过门控后按比例尝试 AI（默认约一半），失败仍发原语料 |
| **弱场景** | 其余日常接话 | 继续语料底盘；AI 介入更克制 |

强场景管线大致是：**选句 →（必要时）润色 → 轻顺口气**；任一步失败就回落语料，不会硬编一句「像机器人」的话顶上去。

接话积极程度、强场景冷却 / 尝试比例等可在控制台调整；详见 [复读插件](/plugins/repeater)。

## `@牛牛` 闲聊

- 仅明确 `@牛牛` 时触发
- 须打开总闸 **`LLM_CHAT_ENABLED`**，并配置好 Provider
- 比日常接话更自由：可带会话、记忆等能力
- 同样会吃到牛格、情感与本群 **表达参考**

详见 [闲聊插件](/plugins/llm_chat)。

## 反哺与表达库（自动变「更像本群」）

AI **成功发出**之后，还可能：

| 机制 | 作用 |
| --- | --- |
| **反哺写回** | 把合适的答句收进接话语料审批 / 晋升（强场景更优先进入可写回） |
| **单群表达库** | 记住「什么场合常说什么」；之后注入 `@` 与强场景提示，不跨群共享 |

因此偶发「说法变了 / 语料变多」往往是闭环在学，不一定是故障。相关开关在控制台「智能对话」通用配置（如收集反哺、表达注入 / 学习）。

## 配置 `LLM_REPEATER_MODE`

控制**接话**是否使用 AI（不影响 `@` 闲聊总闸）。总闸 **`LLM_CHAT_ENABLED`** 关闭时，下表均不生效。

| 值 | 效果 |
| --- | --- |
| `off` | 纯语料接话，AI 不介入 |
| `select` | 命中语料时 AI 选句（推荐默认） |
| `select_polish_lite` | 选句为主，少数回复轻润色 |
| `select_fallback` | 选句；语料缺失时才现编 |
| `fallback` | 仅语料缺失时 AI 现编 |
| `polish` / `both` | 遗留：以润色 / 补位为主（仍可用） |

总闸与装法 → [AI 扩展](ai.md)。
