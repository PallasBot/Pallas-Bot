# 在线统计与社区主站

[Pallas 社区中心](https://stats.pallasbot.top/) 是面向大家的公开主站：在线牛牛气泡墙、部署概览，以及**社区投稿墙**（金句 / 截图）。

本机通过插件 **在线统计（pb_stats）** 定期上报「有多少牛在线」等聚合信息，供主站与控制台「统计与语料」展示。升级后一般**不用改任何配置**。

> 主站**不提供**共享语料开关。社区共享接话库见 [语料联邦](/common/corpus)，默认关闭。

## 主站上能看到什么

| 内容 | 说明 |
| --- | --- |
| 在线气泡墙 | 公开了名册的牛牛头像 / 昵称与在线状态 |
| 部署概览 | 全网大致部署与在线规模 |
| 社区投稿墙 | 文字金句与截图轮换展示 |

## 本机默认行为

| 能力 | 默认 | 说明 |
| --- | --- | --- |
| 在线统计上报 | **开启** | 单进程 / hub 上报；分片 worker 不上报 |
| 名册：头像与昵称 | **开启** | 可出现在主站气泡墙 |
| 名册：QQ / 资料卡链接 | **关闭** | 需在插件页单独打开 |
| 社区共享语料 | 关闭 | 与本文无关，见 [语料联邦](/common/corpus) |

不想出现在社区统计里时：打开 **插件 → 在线统计（pb_stats）** 关闭上报，或在配置里设 `[community_stats] enabled = false`。

## 多机协同（跨部署去重）

与在线统计上报无关。多套牛牛要共用社区协同池时：控制面默认开启；较新版本会在启动时自动写入入池密钥并拉取去重配置。同池后会互认友军；普通口令按群归属（默认约每 12 小时轮换），闲聊 / LLM 只靠 claim。热群入站还会保口令、节流闲聊，见 [语料联邦 · 热闹群与入站设计](/common/corpus#热闹群与入站设计行为说明)。共池入口说明见 [多套牛牛共池](/common/corpus#多套牛牛共池进阶)；控制台 **统计与语料 → 多机协同**。

## 调整名册与隐私

入口：**插件 → 在线统计（pb_stats）**

- 关掉上报：本部署不再进入社区在线统计
- 关掉「头像昵称公开」：气泡墙不展示该部署的牛
- 单只牛可在 **实例与连接 → 某只牛** 里退出社区名册
- 心跳**不上报**群号或消息正文

控制台 **统计与语料** 可查看全网与本部署的只读概况，并跳转到上述插件页。

## 社区投稿墙

| 入口 | 说明 |
| --- | --- |
| **统计与语料 → 社区投稿** | 本机提交 / 查看 / 撤下本部署投稿 |
| 主站投稿区 | 公开展示已发布内容（只读） |

简要规则：

- 正文最多约 500 字；图片可选（常见格式，体积勿过大）；正文与图片至少其一
- 可绑定 Bot 账号（带头像昵称展示）；不绑定时带图投稿按截图展示
- 有频率限制；**提交即公开展示**，请勿带敏感信息截图
- 仅本部署可撤下自己的投稿

## 配置项（可选）

多数保持默认即可。常用项在 WebUI 插件页，或 `config/pallas.toml` 的 `[community_stats]`：

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | 是否上报在线统计 |
| `interval_sec` | `300` | 上报间隔（秒） |
| `roster_public_profile` | `true` | 是否公开头像与昵称 |
| `roster_public_qq` | `false` | 是否公开 QQ / 资料卡链接 |

使用官方社区中心时，服务地址与口令保持默认即可（公开中心一般无需填写口令）。

旧键 `roster_public=true`（或环境变量 `PALLAS_COMMUNITY_STATS_ROSTER_PUBLIC`）会同时视为 QQ 与头像昵称两项均开启。
