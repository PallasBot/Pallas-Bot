# 方舟资料 MCP

牛牛提供了一个公开的只读 MCP 服务：可以查干员、技能、敌人，也能检索 PRTS 本地资料并读取出处。它是给 MCP 客户端调用的协议接口，不是网页——不需要密钥、注册或登录。

## 直接用

把下面的地址复制到支持远程 **Streamable HTTP** 的 MCP 客户端（桌面或服务端均可）：

```text
https://mcp.pallasbot.top/mcp
```

| 接入项 | 值 |
| --- | --- |
| 地址 | `https://mcp.pallasbot.top/mcp` |
| 传输 | Streamable HTTP |
| 鉴权 | 无（公共只读） |

添加后客户端会列出可用工具；之后正常提问，由模型自行决定是否调用。用浏览器直接打开这个地址不会得到页面，这是正常的，它不是一个网站。

## 能做什么

服务固定提供 8 个只读工具，分两组：

| 分组 | 工具 |
| --- | --- |
| 方舟结构化查询 | 干员信息 / 干员搜索 / 技能 / 敌人信息 / 敌人搜索 |
| PRTS 资料检索 | 资料搜索 / 原文读取（带出处）/ 时间线 |

可以这样问：

- 「查一下帕拉斯的三技能」
- 「搜索泰拉参考资料，把出处一起给我」
- 「查一下泰拉历史年表」

## 范围与限制

- 托管实例当前只安装了 PRTS `references` 参考资料包，不含完整剧情包或终末地资料。
- 数据是已同步的快照，不保证实时更新，也不等同于精确的游戏版本。
- 这是公共共享服务，有请求频率与并发限制；遇到 `429` 请稍后重试，不承诺可用性 SLA。
- 只读，不提供群聊记录、管理操作或文件写入。

## 来源与条款

- 结构化数据来自 [ArknightsGameData](https://github.com/Kengxxiao/ArknightsGameData)。
- PRTS 资料来自 [PRTS.chat](https://prts.chat/) 及其明日方舟数据集。

内容仍受各自来源的使用条款约束，可检索不代表可以任意转载。客户端初始化说明里的源码链接指向对应运行版本的公开源码归档。
